# Unreal Engine UI Navigation with MVVM & Common UI

This repository contains implementation files based on the tutorial **"Handling UI Navigation with MVVM and Common Activatable Widgets"** by Irene Zanon (Lead Tech UI Designer @ Epic Games) at Unreal Fest Orlando 2025.

## Overview

The goal of this project is to implement functional UI navigation for an inventory screen using the MVVM pattern and Common UI features in Unreal Engine 5.

## Content Covered

* **MVVM View Bindings:** Connecting UI widgets to View Model properties.
* **Selection View Model:** Managing category and item selections with centralized setters.
* **Focus Management:** Handling Slate focus hierarchy using `Get Desired Focus Target` and `Request Refresh Focus`.
* **Debugging Tools:** Utilizing Widget Reflector, ViewModel Debugger, Slate Debugger, and Blueprint Debugger.
